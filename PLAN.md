# План: репорт по тратам трипа Франция → Исландия → Швейцария

**Даты трипа:** ~20.07 – 01.08.2026 (Париж → 24–29.07 Исландия → 29–31.07 Швейцария/Лихтенштейн → 31.07 GVA→SKG).
Контекст сопоставлен со страницами Notion: «Исландия · 24–29 июля», «Швейцария и Лихтенштейн · 29–31 июля», «Что взять с собой · 21 июля – 1 августа».

## Статус: выполнено

Артефакты пересобираются из `data/*.json` через `scripts/build.py`. См. `README.md`.

## 1. Источники данных

| Источник | Формат | Особенности |
|---|---|---|
| NBG Mastercard *1626 | xlsx, греческий | Основная карта; с неё шли топ-апы Revolut |
| NBG Prepaid *2848 | xlsx, греческий | Мелкие покупки (время в выписке часто 21:00) |
| Revolut EUR | csv | Основная карта в поездке |
| PayPal | csv | Booking.com, Aegean, SWISS и др. |
| Gmail | подтверждения | Брони, инвойсы, подписи |

## 2. Модель данных (`data/transactions.json`)

Единая схема: `dt`, `src`, `desc`, `label`, `category`, `stage`, `pretrip`, `amount_eur`, плюс:

- `personal` — не делится на 3 (например, Баку→Париж для Фрозы);
- `trip_day` — день поездки, если settlement позже (Uber 30.07 → 22.07);
- `time_unknown` — prepaid без реального времени.

Скоуп: Trip / Pre-trip / Excluded (`data/excluded.json`).

## 3. Категории и этапы

Категории: Перелёты · Жильё · Аренда авто · Топливо · Парковки · Рестораны · Продукты · Активности · Шопинг · Транспорт · Страховка · Прочее.

Этапы: Pre-trip (флаг) · Франция · Исландия · Швейцария·Лихтенштейн · Общее.

## 5. Допущения

- Всё в EUR (курс списания банка).
- Депозит SIXT (REVERTED) — не трата.
- Geirland (−671,92) учитывается как **пре-трип** (бронь/оплата заранее).
- Язык репорта — русский.
- Наличные: снятий в скоупе трипа не было.

## 6. Исправления относительно первой версии

- Uber settlement 30.07 помечен `trip_day=2026-07-22`.
- Подписи французских кафе по мерчантам; аптека → «Прочее».
- Financing-блок сверен с фактическими суммами по источникам (Revolut 3 933,39 € в отчёте, не 4 865).
- «На человека» = shared ÷ 3 (без personal).
